# Day 07 — Scikit-learn ML Pipeline 🔄

## 🎯 Objective
Understand the complete workflow for taking raw data through preprocessing, modeling and evaluation.

## 🏗️ Pipeline

```text
Raw Data
   ↓
Cleaning
   ↓
Feature Engineering
   ↓
Train/Test Split
   ↓
Model Training
   ↓
Evaluation
   ↓
Model Saving
```

## 📚 Concepts Covered
- Data cleaning
- Feature engineering
- Train/test split
- Model training
- Evaluation
- Model persistence

## 🧠 Key Takeaways
A machine learning system is a pipeline, not just a model.

## 🚀 Why It Matters for GenAI
The same engineering mindset is used later for embedding pipelines, RAG pipelines, evaluation pipelines and production AI systems.
