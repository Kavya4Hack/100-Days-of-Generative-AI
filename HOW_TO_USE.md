# How to use these files

These are portfolio-ready starter/implementation files for Days 01–20.

## Run Python examples

From the repository root:

```bash
python Day-01-Python-Revision/python_revision.py
python Day-02-OOP/llm_client.py
python Day-03-APIs/api_client.py
python Day-04-NumPy-Pandas/data_analysis.py
python Day-05-ML-Revision/ml_workflow.py
python Day-06-ML-Metrics/metrics.py
python Day-07-Sklearn-Pipeline/pipeline.py
python Day-11-Neural-Network-Fundamentals/neuron.py
python Day-12-Forward-Backpropagation/forward_backward.py
python Day-13-Gradient-Descent/gradient_descent.py
python Day-14-PyTorch-Fundamentals/pytorch_fundamentals.py
python Day-15-Neural-Network/neural_network.py
python Day-16-Training-Loop/training_loop.py
python Day-17-PyTorch-Data-Pipeline/data_pipeline.py
python Day-18-CNN-RNN-LSTM-GRU/architectures.py
python Day-19-Neural-Network-Build/neural_network_build.py
```

For Day 20:

```bash
cd Day-20-Classification-System
python train.py
python evaluate.py
```

## Important

The files are clean implementations aligned with the documented Day 01–20 topics. They should be treated as the repository implementation layer and adapted with your actual experiments, outputs, screenshots and results as the journey progresses.
