# Day 05 — Machine Learning Revision 🤖

## 🎯 Objective
Refresh the core Machine Learning concepts required for the transition into Deep Learning and GenAI.

## 📚 Concepts Covered
- Supervised learning
- Unsupervised learning
- Regression
- Classification
- Clustering
- Training and testing data
- Cross-validation

## 🧠 Learning Map

```text
Machine Learning
├── Supervised Learning
│   ├── Regression
│   └── Classification
│

    └── Clustering
```

## 🧠 Key Takeaways
- Supervised learning learns from labeled examples.
- Unsupervised learning discovers structure without target labels.
- Train/test separation helps measure generalization.
- Cross-validation provides a more robust estimate of model performance.

## 🚀 Why It Matters for GenAI
Understanding classical ML makes it easier to understand how modern neural and language models are trained and evaluated.
