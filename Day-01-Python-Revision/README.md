# Day 01 — Python Revision 🐍

## 🎯 Objective
Strengthen the Python fundamentals required for Machine Learning and Generative AI engineering.

## 📚 Concepts Covered
- Functions
- `*args` and `**kwargs`
- Lambda functions
- List, set and dictionary comprehensions
- Iterators
- Generators
- Decorators
- Writing reusable Python utilities

## 🛠️ Build
### Python Utility Toolkit
Built a small utility toolkit containing **10 reusable Python functions** to practice clean, modular Python.

## 🧠 Key Takeaways
- Functions are the basic building blocks of reusable AI code.
- `*args` and `**kwargs` make APIs and utility functions flexible.
- Comprehensions provide concise data transformations.
- Iterators and generators enable lazy, memory-efficient processing.
- Decorators allow behavior to be added to functions without modifying their core logic.

## 🚀 Why It Matters for GenAI
Python is the primary language used throughout the GenAI stack, from data preparation and model training to APIs, RAG pipelines and agents.
