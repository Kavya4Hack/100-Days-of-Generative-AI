# Day 18 — CNN, RNN, LSTM & GRU 🧠

## 🎯 Objective
Understand the historical and architectural importance of major neural-network families.

## 📚 Architectures Covered

### CNN — Convolutional Neural Network
Designed primarily for spatial patterns such as images.

### RNN — Recurrent Neural Network
Designed to process sequential information.

### LSTM — Long Short-Term Memory
An RNN variant designed to better preserve information over longer sequences.

### GRU — Gated Recurrent Unit
A simpler gated recurrent architecture related to LSTM.

## 🧠 Key Takeaways
The goal was not deep specialization in these architectures, but understanding why they mattered historically and how they led toward modern Transformer-based systems.

## 🚀 GenAI Connection
Transformers largely replaced recurrent architectures for many language tasks because attention enables more effective parallel processing and long-range dependency modeling.
