# Day 06 — Machine Learning Metrics 📈

## 🎯 Objective
Learn how to evaluate ML models using metrics appropriate to the problem.

## 📚 Classification Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## 📚 Regression Metrics
- MAE
- MSE
- RMSE
- R²

## 🎯 Metric Selection
The correct metric depends on the problem and the cost of different errors.

```text
Classification → Accuracy / Precision / Recall / F1 / ROC-AUC
Regression     → MAE / MSE / RMSE / R²
```

## 🧠 Key Takeaways
A model is not "good" simply because one metric is high. Evaluation must match the real objective of the system.

## 🚀 Why It Matters for GenAI
Evaluation becomes even more important for LLM and RAG systems, where simple accuracy may not fully describe quality.
