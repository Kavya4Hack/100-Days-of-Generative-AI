## 🎯 Objective
Learn the core PyTorch concepts required to build and train neural networks.

## 📚 Concepts Covered
- Tensors
- Tensor shapes
- Devices

## 🔢 Tensor
A tensor is PyTorch's fundamental data structure for numerical computation.

## 📐 Shape
Tensor shape describes the dimensions of the data.

## ⚡ Device
PyTorch can perform computation on:
- CPU
- GPU

```text
Data

Tensor

Choose Device
 ↓
Operations

Neural Network
```

Understanding tensor shape and device placement is essential for avoiding many deep-learning errors.
