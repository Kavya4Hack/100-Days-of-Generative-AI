# Day 09 — Git & GitHub 🐙

## 🎯 Objective
Learn the version-control workflow required for professional software and AI engineering.

## 📚 Concepts Covered
- Git fundamentals
- Repository creation
- `git add`
- `git commit`
- `git push`
- Branching
- Merging
- `.gitignore`
- README documentation

## 🛠️ Build
Started the **100 Days of Generative AI** GitHub repository to document the complete learning journey.

## 🧠 Key Takeaways
- Git tracks project history.
- Branches support isolated development.
- `.gitignore` prevents unnecessary or sensitive files from entering the repository.
- Good documentation makes technical work understandable to others.
