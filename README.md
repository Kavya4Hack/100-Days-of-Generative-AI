## 🎯 About This Journey

This repository documents my **100-day journey to become a Generative AI Engineer**.

The goal is not just to study concepts, but to **learn by building**.

Throughout these 100 days, I am progressively developing my understanding of:

* Python for AI/ML
* Mathematics for Machine Learning
* Machine Learning
* Deep Learning
* PyTorch
* Neural Networks
* NLP
* Transformers
* Large Language Models (LLMs)
* Prompt Engineering
* Embeddings
* Vector Databases
* Retrieval-Augmented Generation (RAG)
* AI Agents
* Multi-Agent Systems
* LLM Evaluation
* Fine-tuning
* APIs
* Deployment
* Production-oriented AI systems

Each day contains concepts, implementation, experiments, and practical work.
