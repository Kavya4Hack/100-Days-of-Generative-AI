## 🔄 Training vs Validation vs Evaluation

### Training
The model updates its parameters using the training data.

### Validation
Validation data is used during development to monitor generalization without updating model parameters.

### Evaluation
The final model is assessed on held-out data to measure performance.

## 💾 Model Saving
The trained model is saved so it can be reused later without retraining from scratch.

## 🧠 Key Takeaways
A practical ML system requires more than a model definition.

It needs:

```text
Data
→ Training
→ Validation
→ Evaluation
→ Persistence
```

This is an important transition from learning individual PyTorch concepts to building an actual ML system.
