# Day 08 — SQL 🗄️

## 🎯 Objective
Build the database querying skills required for data-driven AI applications.

## 📚 Concepts Covered
- `SELECT`
- `WHERE`
- `JOIN`
- `GROUP BY`
- `HAVING`
- Subqueries
- CTEs
- Window functions

## 🧠 Key Takeaways
SQL is essential for retrieving, filtering, aggregating and preparing structured data.

## 🚀 Why It Matters for GenAI
Production AI applications often combine LLMs with databases, user data, analytics and application state. Strong SQL skills make those systems easier to build.

## 🔧 Focus
The emphasis was on understanding query logic and how multiple SQL operations combine to answer real data questions.
