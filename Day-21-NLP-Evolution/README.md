# 🧠 What is NLP?

**Natural Language Processing (NLP)** is a field of Artificial Intelligence that focuses on enabling computers to understand, process, and generate human language.

Examples:

- Chatbots
- Text classification
- Sentiment analysis
- Machine translation
- Search engines
- Text summarization
- Question answering
- Large Language Models

The major challenge is:

> Computers do not naturally understand words the way humans do.

So NLP evolved through several techniques for converting language into representations that machines can process.
