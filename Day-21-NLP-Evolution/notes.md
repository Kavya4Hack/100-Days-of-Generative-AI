# Day 21 — Quick Revision Notes

## NLP

Natural Language Processing allows computers to work with human language.

## Evolution

```text
BoW → TF-IDF → Word2Vec → RNN → LSTM → Attention → Transformer → LLM
```

| Technology | Remember This |
|---|---|
| BoW | Count words |
| TF-IDF | Find important words |
| Word2Vec | Represent words as vectors |
| RNN | Process sequences |
| LSTM | Remember important information |
| Attention | Focus on relevant information |
| Transformer | Scale attention efficiently |
| LLM | Learn and generate language at large scale |

## Most Important Understanding

```text
Count words

Measure importance

Represent meaning

Process sequences

Remember information

Focus on relevant information
    ↓
```
